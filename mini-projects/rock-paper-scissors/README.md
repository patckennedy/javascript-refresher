# ✊📄✂️ Rock Paper Scissors (Mini Project)

A simple interactive JavaScript game where the player competes against the computer in a classic game of Rock, Paper, Scissors.

This mini project is part of my **JavaScript Refresher** series.

---

## 🚀 Features

- Play Rock, Paper, or Scissors against the computer
- Random computer choice generation
- Instant win, lose, or tie results
- Live score tracking
- Interactive button controls
- Beginner-friendly responsive layout
- Clean and simple user interface

---

## 🧠 What I Practiced

- Selecting DOM elements with `getElementById()`
- Handling button clicks with `addEventListener()`
- Creating and calling functions
- Using arrays to store game choices
- Generating random values with `Math.random()`
- Writing conditional logic with `if`, `else if`, and `else`
- Updating text dynamically with `textContent`
- Tracking and updating scores using variables
- Structuring a simple interactive game with JavaScript

---

```bash
rock-paper-scissors-mini/

├─ style.css    # Styling and page layout
├─ script.js    # Game logic and score tracking
└─ README.md    # Project documentation
```

---

## 💡 How to Use

1. Open **index.html** in your browser
2. Click Rock, Paper, or Scissors
3. The computer will make a random choice
4. The winner of the round will be displayed
5. Scores update automatically after each round
