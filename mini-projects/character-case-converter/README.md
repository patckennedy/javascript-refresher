# 🔤 Character Case Converter

A simple beginner-friendly tool that converts text into different character cases with the click of a button.
This project is part of my **JavaScript Refresher** series.

---

## 🚀 Features

* Convert text to **UPPERCASE**
* Convert text to **lowercase**
* Capitalize the first letter of each word
* Clear the input and output
* Automatically return focus to the text area after clearing
* Responsive layout for smaller screens
* Simple and clean user interface

---

## 🧠 What I Learned

* Selecting DOM elements with `document.getElementById()`
* Handling button clicks with `addEventListener()`
* Reading user input with the `.value` property
* Updating page content with `.textContent`
* Converting strings with `toUpperCase()` and `toLowerCase()`
* Splitting strings into arrays with `split()`
* Looping through arrays with `map()`
* Working with individual characters using `charAt()`
* Extracting part of a string with `slice()`
* Combining arrays back into strings with `join()`
* Using conditional statements to handle empty values
* Returning focus to an input with `.focus()`

## ▶️ How to Use

1. Open `index.html` in your browser.
2. Type or paste text into the text area.
3. Click **UPPERCASE** to convert all letters to uppercase.
4. Click **lowercase** to convert all letters to lowercase.
5. Click **Capitalize Words** to capitalize the first letter of each word.
6. Click **Clear** to reset the converter.
