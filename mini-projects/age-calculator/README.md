# 🎂 Age Calculator (Mini Project)

A simple beginner-friendly JavaScript application that calculates a user's current age based on their date of birth.

This project is part of my **JavaScript Refresher** series and focuses on working with dates, user input, and DOM manipulation.

---

## 🚀 Features

- Enter your date of birth using a date picker
- Calculate your current age instantly
- Prevent empty input with validation
- Detect and reject future dates
- Display the calculated age in years
- Clean and beginner-friendly user interface

---

## 🧠 What I Learned

While building this project, I practiced:

- Selecting HTML elements with `getElementById()`
- Handling button click events with `addEventListener()`
- Creating reusable JavaScript functions
- Reading user input with `.value`
- Working with the JavaScript `Date` object
- Calculating age using dates
- Using conditional statements (`if`)
- Validating user input
- Updating webpage content with `textContent`
- Using template literals for dynamic output
