# 💰 Expense Tracker (Mini Project)

A simple beginner-friendly application that lets users add expenses and automatically keeps track of the **total amount spent**.  
This project is part of my **JavaScript Refresher** series.

---

## 🚀 Features

- Add an expense name
- Enter an expense amount
- Display a list of expenses
- Automatically calculate the total amount spent
- Basic input validation
- Clean and simple user interface

---

## 🧠 What I Learned

- Selecting HTML elements using `getElementById()`
- Handling button clicks with `addEventListener()`
- Creating reusable functions
- Validating user input with `if` statements
- Creating HTML elements dynamically using `createElement()`
- Adding elements to the page with `appendChild()`
- Updating text dynamically with `textContent`
- Formatting numbers with `toFixed(2)`

---

```text
expense-tracker-mini/

└─ script.js     # Expense tracking functionality
```

---

## 💡 How to Use

1. Open **index.html** in your browser.
2. Enter an expense name.
3. Enter the expense amount.
4. Click **Add Expense**.
5. The expense is added to the list and the total is updated automatically.
