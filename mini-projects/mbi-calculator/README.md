# ⚖️ BMI Calculator (Mini Project)

A simple beginner-friendly JavaScript application that calculates a user's **Body Mass Index (BMI)** based on their height and weight.

This project is part of my **JavaScript Refresher** series.

---

## 🚀 Features

- Calculate BMI using height (cm) and weight (kg)
- Instant BMI calculation
- Display BMI rounded to one decimal place
- Show BMI category:
  - Underweight
  - Normal Weight
  - Overweight
  - Obese
- Beginner-friendly and responsive interface
- Simple form validation using required inputs

---

## 🧠 What I Practiced

- Structuring a webpage with semantic HTML
- Styling forms with CSS
- Selecting DOM elements with `getElementById()`
- Handling form submissions using `addEventListener()`

## ▶️ How to Use

1. Open `index.html` in your web browser.
2. Enter your height in **centimeters (cm)**.
3. Enter your weight in **kilograms (kg)**.
4. Click the **Calculate BMI** button.
5. View your BMI value and health category instantly.

---

## 🎯 BMI Categories

| BMI | Category |
|------|----------|
| Below 18.5 | Underweight |
| 18.5 – 24.9 | Normal Weight |
| 25.0 – 29.9 | Overweight |
| 30.0 and above | Obese |
